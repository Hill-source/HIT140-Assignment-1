# Project Overview
This repository contains the Python code, datasets and visualisations developed by Group 48 for the HIT140 Foundations of Data Science group project. The project investigates the following overall research question: At the FIFA World Cup 2026, how did younger and older players differ in playing involvement and individual performance?

The project consists of four separate analytical tasks:
1. Playing Involvement
   Analysis of the mean playing time per appearance among eligible outfield players.
2. Finishing Efficiency
   Comparison of finishing performance between younger and older players.
3. Passing Performance
   Analysis of passing performance among players who met the minimum passing-attempt requirement.
4. Fouls Suffered
   Comparison of fouls suffered by younger and older players.
